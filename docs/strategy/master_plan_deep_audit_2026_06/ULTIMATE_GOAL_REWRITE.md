# ULTIMATE_GOAL_REWRITE v2 — 基于原文（取代 v1 推断版）

## 关键修正（v1 → v2）

v1 在未读原文时主张"删除 GUWM"。读原文后修正：**§4 把 GUWM 写成
research program（'computational protocol for cross-domain unification,
not a completed physical theory'）——作为 L0 这是合法且诚实的**，
v1 的"必须删除"判定撤回。真正的问题有两个：
①它出现在对外**第一句话**（§1 strapline）的位置——第一接触面就
要求听众同时消化 quantum formalism + world model + GUWM 三个高风险词；
②它与 sprint 裁判主线的双魂冲突（V1'）。
所以 v2 的重写不是替换北极星，是**重排北极星的层级和出场顺序**。

- 用途：合规场合、学术 talk 的第一句。

> **"Omytea 是第一个敢被评分的世界模型：每一次预测都预登记、
> 对照基线评分、可由任何人复算——因为在 AI 能生成无限种未来的
> 时代，稀缺的不是预测，是证明。"**

  §1 冲突；N2' 忠实于"选手带收据"的合题（V1' 修补案），保留了
  世界模型身份，把 §2.7.1 那句最好的话放到了第一句的位置。

## 推荐结构（v2）

- **对外第一句 = N2'**（敢被评分的世界模型）。quantum formalism
  降到第二段（保留 §1 的全部诚实限定）；GUWM 降到研究语境（N3）。
- **内部 = N5 合一版**（GUWM 方向 + 现实账本路径）。

  规矩开源。"** 通过。
