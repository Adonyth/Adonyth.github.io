# MASTER_PLAN_MISSING_OPPORTUNITIES — 被低估与遗漏的机会

> 排序按"升级潜力 × 当下可验证性"。每条标注证据状态。

## O1 ｜ 开放标准玩法：Receipt Protocol（被低估：把 schema 当内部细节）

- **Opportunity**：把预测收据的 schema + 验证规则发布为开放标准
  （"预测界的 RSS"）：任何人可实现、任何账本可互验，Omytea 运营
  参考注册表（reference registry）。
- **为什么属于 Omytea**：schema 已存在且经过测试（ledger/ + PRD 数据
  模型）；审计纪律文档是标准的"规范性散文"现成底稿。
- **为什么是现在**：品类空白期定义标准的成本最低；等有竞争者再发布
  就成了"又一家的格式"。
- **为什么被低估**：plan 把 schema 看作产品实现细节 [INFERRED]，
  而标准是单人项目撬动文明尺度的经典杠杆（参照 RSS、Markdown、
  robots.txt——都是极小团队定义的）。
- **与 plan 关系**：不改变 D1 wedge，叠加在其上（产品=托管实现，
  标准=分发与正当性引擎）。
- **证据需求/30 天可验证**：是——发布 spec v0.1 到公开 repo，
  看是否有任何第三方 star/issue/实现意向（弱信号即可）。
- **风险与反例**：标准无人理睬（大概率，但成本≈一周整理）；
  标准被大玩家劫持（防：宽松许可+先发的 registry 网络效应）。

## O2 ｜ Time-locked benchmark：免疫污染的评测装置（被低估：把 ledger 当 demo）

- **Opportunity**：预登记+未来才 resolve 的预测集，**构造上不可能
  泄入训练集**——而 benchmark 污染是当前 AI 评测的公认危机
  （流行基准污染率最高达 45%，动态基准又牺牲纵向可比性 [WEB]）。
  Omytea 的账本机制即一台持续生产 contamination-proof eval 的机器。
- **为什么属于 Omytea**：这不是新功能，是现有机制的学术再定价。
  finance ledger、golf 数据集、civilization verdicts 全是该装置的实例。
- **为什么是现在**：污染问题 2024–2026 文献爆发 [WEB]，
  解决方案窗口开着；labs 有真预算（eval 采购已是成熟支出）。
- **为什么被低估**：plan 把 ledger 当"机制证明 demo"；学术界把
  time-locked eval 当"成本太高的理想"——Omytea 恰好把成本结构做对了
  （收据服务的副产品就是评测集）。
- **与 plan 关系**：给 D1 wedge 加第二买家（agent 团队之外：模型
  评测方/实验室）；给"研究版"叙事一个可发表的锚。
- **30 天可验证**：部分——写 2 页 position note + 找 1 个做 eval 的
  研究者/从业者反应测试（访谈名单里加 1 人即可）。
- **风险**：学术周期慢；Scale/Surge 等标注厂商向此延伸（他们有
  人力管道但没有预登记机制资产）。

## O3 ｜ Civilization verdicts = 旗舰收据（被遗漏：当成无关 side project）

- **Opportunity**：civilization-tech-path-research 的判定（哪条技术
  路径会成）本质是**最长时间尺度的预测**。把 10 个判定作为公开收据
  预登记——"我们对十年尺度的问题也敢留下不可改的记录"——
  是收据机制最高姿态的自我演示，也是内容分发的天然爆点。
- **为什么被低估**：plan 把它归类为"文章/worksheet 素材"（Phase 1–2
  的处理），没看到它和主线是同一个机制的两端（秒级 agent claim ↔
  十年级文明 claim，中间是同一张收据）。
- **与 plan 关系**：D2 公开橱窗的旗舰内容；零新基建（复用 receipt 页）。
- **30 天可验证**：是——발布 3 条 civilization 收据到 receipt 示例页，
  看分享/讨论量。
- **风险**：判定质量绑定个人声誉（十年后被打脸——但这恰是机制的
  诚实性卖点）；需 FP-9 发布审查防越级 claim。

## O4 ｜ Agent 责任制的监管顺风（被遗漏：合规只被当成本）

- **Opportunity**：plan 把合规全部计为摩擦/风险。反面被漏掉：
  AI 责任与透明度监管（EU AI Act 类）正在制造"可验证记录"的
  **强制需求**——审计层可能从 nice-to-have 变成 compliance-driven 采购。
- **证据状态**：[HYPOTHESIS]——监管文本是否真的要求 agent 输出的
  历史可验证性，需查证（已入 WEB_RESEARCH_BACKLOG P0-2 扩展）。
- **30 天可验证**：桌面研究可半验证；访谈中加一问
  （"合规有没有问过你们 agent 的决策记录?"）。
- **风险**：监管时间表慢于创业窗口；按真实查证结果决定是否写入 plan。

## O5 ｜ "对账"作为世界模型时代的卖水生意（格局重定位，O1–O4 的总和）

- **Opportunity**：2026 年 $1.3B+ 涌入世界模型赛道 [WEB]。所有世界
  模型都需要回答同一个问题：**"你的模型对现实的预测到底准不准、
  在哪些域准"**——这恰是 Omytea 机制的输出。世界模型越多、越竞争，
  中立记分牌越刚需。plan 当前把世界模型当目标（V1 漏洞）；
  正确姿势是把世界模型当**客户群**。
- **为什么现在**：竞赛刚起步，记分牌空位；等竞赛分出头部，
  头部自己做记分牌的动机就出现了。
- **30 天可验证**：弱验证——O2 的 position note 同时服务此项。
- **风险**：世界模型公司现在还不觉得需要外部评分（太早）；
  对冲：D1（agent 团队）是同一机制的近端付费者，先吃近的。

## 应该降级的"伪机会"（看似宏大，实际反向）

- **自建预测模型/信号研究**（quantum-core 若越出 gate 即属此类）：
  与中立定位冲突，撞资本竞赛，gate 管辖不变。
- **多 vertical 并行扩张**：resolution 供给是约束，一次一个。
- **链上/区块链化**：时间戳锚定用 RFC3161/OpenTimestamps 够用，
  token 化叙事引入的噪音远大于信任增益（do-not-use 级）。
