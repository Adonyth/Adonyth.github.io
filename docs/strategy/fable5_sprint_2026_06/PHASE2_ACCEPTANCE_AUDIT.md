## 逐文件审计

### 1. 00_README_SOURCE_STATUS.md
- **Source basis**：明确（自身就是 source 状态声明）。
- **事实分级**：是——全部为 verified fact（环境事实）。
- **可执行下一步**：有（[VERIFY-LOCAL] 核对流程，≤60 分钟）。
- **隐私/合规风险**：无。反而是隐私边界的留痕证据。
- **空话**：无。
- **需补读源文件**：本文件不需要；它指挥别的文件去补。
- **判定：保留。** 唯一行动：founder 执行核对流程（已入行动队列 AQ-3）。

### 2. FABLE5_MASTER_PLAN.md
- **Source basis**：任务描述上下文；[VERIFY-LOCAL] 标注到位。
- **事实分级**：轨道优先级、stop rules 是决策（明确）；工具能力假设标注了。
- **可执行下一步**：每日 done criteria 可判定——这部分合格。
- **隐私/合规**：无。
- **空话（诚实自查）**：**有**。(a) 上午/下午/晚上三时段编排是计划者的舒适幻觉，
  真实日程不会按它走，会产生"今天又没按计划"的虚假负罪感；
  (b) D5"文章初稿 ≥ 可发给朋友试读的完成度"这类 criteria 边界模糊；
  (c) 降级表的"轻度/中度/重度"缺乏可测的触发线。
- **判定：压缩。** 处理方式：不重写此文件（沉没成本停损），
  而是用 NEXT_7_DAYS_ACTION_QUEUE 取代其 D1–D7 部分作为实际执行依据；
  此文件降格为"轨道优先级 + stop rules + 降级表"三节有效，其余仅供参考。

### 4. OMYTEA_EXTERNAL_STORY_PACK.md

### 5. V10_V2_RESEARCH_GATE_PLAN.md
- **Source basis**：诚实——明确声明未读源文件、拒绝复述理论。这是对的。
- **事实分级**：元规则全部是决策（明确）；无伪装的事实。
- **可执行下一步**：**当前为零**。5 个槽位不填，文档是惰性的。
  这不是缺陷（设计如此），但必须如实标注：**此文档的价值 100% 取决于
  founder 花 30 分钟填槽**。填槽不发生 = 整条 T2 轨道实际不存在。
- **隐私/合规**：无。
- **空话**：无，但有"制度感安慰剂"风险——拥有一个漂亮的 gate 协议
  会产生"研究线已被管住"的错觉，而管住它的是填槽+冻结这个动作本身。
- **判定：保留。** 行动队列中给它一个带 stop condition 的明确任务（AQ-7）：
  **如果 D3 结束仍未填槽，T2 整条轨道自动按 FAIL-budget 关闭**——
  把惰性资产变成有死线的资产。

## 跨文件审计发现

1. **最大系统性风险不在任何单个文档里**：是"文档完成感"替代"第一行真实数据"。
   全包 1254 行,目前产生的真实预登记记录是 **0 行**。Phase 2 的全部意义
   是把这个数字变成非零。
2. **三个文档要求 founder 在 72 小时内做不可委派动作**
   （核对标记、填槽、发访谈消息）——这是当前的关键路径,全部进入
   FOUNDER_MANUAL_ACTIONS,且 TODAY_TOP3 占其二。
3. **无隐私违规**：全包未引用任何敏感文件内容；ledger schema 无个人金融字段。
4. **补读源文件的真实需求排序**：PROJECT_STATE.md（定 C3–C7 级别）>
   两份 gate 源文件（填槽）> WORK_PLAN_V418（golf 回填）> survey（universe 确认）
   > 其余（story pack 细节润色，可推迟）。
