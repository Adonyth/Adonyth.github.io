## 1. Gate 的元规则（先于一切内容）

1. **冻结即生效**：本文档槽位填完、commit 之后（D3 上午，2026-06-12），
   pass/fail 阈值、数据 split、评测指标**一律不得修改**。
   发现阈值定错了？那就按错的判，把教训写进复盘，下个周期再开新 gate。
2. **预登记**：所有实验在跑之前，其假设、方法、阈值必须已在 git 历史中。
   跑完之后补写的任何"假设"自动视为无效。
3. **一票 kill**：触发任一 kill criterion，该研究线立即冻结，
   不允许"再试一个变体"。重启需要一个全新的、同样预登记的 gate（V3/V11），
   且必须写明"上次为什么死、这次有什么结构性不同"。
4. **结论二值化**：gate 的输出只有 PASS / FAIL，没有"有希望""接近了""值得再看看"。

## 3. Pass / Fail labels（通用判据，与槽位内容叠加使用）

每条研究线跑完后，按以下顺序打且仅打一个 label：

| Label | 判据 | 后续动作 |
|---|---|---|
| **PASS** | 预登记阈值在预算内达成，且通过第 5 节的 sanity checks | 进入"允许的 claim"清单（第 6 节），规划下一个最小 gate |
| **FAIL-threshold** | 跑完预算，阈值未达成 | 线冻结；写停止声明 |
| **FAIL-by-design** | 开跑前或跑动中发现实验无法回答假设（数据泄漏、baseline 不公平、结果不可判读） | 线冻结；这不算"差一点"，算设计失败 |
| **FAIL-budget** | 预算（run 数/机时/日历）耗尽且无完整结果 | 线冻结；禁止追加预算续跑 |
| **KILLED** | 触发第 4 节任一 kill criterion | 线冻结 + 复盘必写 |

**重要：FAIL 不是耻辱，是 gate 在正常工作。一个从不 FAIL 的 gate 才是坏 gate。**

## 4. Kill criteria（任一触发即 KILLED）

1. **No-tune 违规**：任何人（包括你自己）在看到测试集结果后修改了
   超参、特征、数据 split 或阈值，再跑了一次。哪怕"只是确认一下"。
2. **目标漂移**：发现自己在论证"虽然没过阈值，但换个指标看其实……"。
   换指标 = KILLED。
3. **预算超支**：超出【SLOT-5】预算的任何追加 run。
4. **依赖倒挂**：发现公司任何对外材料、产品决策开始"假设这条线会 PASS"。
   研究线污染主线 = 立即 KILLED（保护主线优先于保护研究线）。
5. **占用挤兑**：连续 3 天该线占用了 T1/T3（叙事/ledger）的预定时段。

## 5. Sanity checks（PASS 的前置条件，缺一不可）

- [ ] 结果可由一条命令复现（固定 seed、固定数据快照）。
- [ ] Baseline 不是稻草人：至少包含一个"无聊但强"的 baseline
      （如历史频率 / 持平外推 / 标准模型默认参数）。
- [ ] 效应在数据的时间维度前后两半上同号（粗糙的稳健性检查）。
- [ ] 评测代码被另一个工具（Codex 或 Cursor 会话）独立审过一遍，
      重点查数据泄漏。
- [ ] 结果数字和预登记阈值的对比写成一行：`观测值 X vs 阈值 Y → PASS/FAIL`。

## 6. 结果出来后的 claim 边界

### 若 PASS（且过 sanity checks）：

**允许说（仅内部 + 正式研究语境）**：
- "在【数据集】上，按预登记阈值【Y】，方法【M】观测到【X】，判 PASS。
  局限：单数据集、未经独立复现、效应大小为【Z】。"
- claim 级别：L3 候选（需独立复现才坐实 L3）。

**仍然禁止**：
- 任何对外的能力性表述（见 PUBLIC_CLAIMS_MATRIX C6/C10）。
- "validated" / "proven" / "quantum advantage" / 把单 gate PASS 外推为方法优势。
- 在 pitch 中提及，除非对方主动问且按 matrix 第 4 节话术回答。

### 若 FAIL / KILLED：

**必须说（内部）**：
- 写一份 ≤1 页的停止声明：假设、阈值、观测值、label、
  "重启此线需要满足的结构性条件"。commit 到 docs/research/。

**允许说（对外，且这其实是加分项）**：
- "我们有一条研究线没通过自己的预登记 gate，我们按规则停了它。"
  ——这是 claim discipline 的活证据，在 Q7 类问题中主动使用。

**禁止**：
- 静默地继续跑（最常见的失败模式）。
- 把 FAIL 重新包装成"初步探索取得经验"。经验写进复盘，线必须死透。
